# 전체 프로그램 흐름

## 시작과 메뉴

1. `main.py`에서 `QuizGame`을 시작한다. 프로젝트 루트의 `state.json`을 시작 시 한 번 읽어 퀴즈 목록과 최고 점수를 메모리에 올린다.
2. 파일이 없으면 기본 CS 퀴즈 5문항 이상과 미기록 상태로 시작한다. 파일 내용이 손상됐으면 안내 후 같은 기본 상태로 복구한다. 그 외 읽기 오류는 안내하고 안전하게 종료한다.
3. 메뉴에서 `1` 퀴즈 풀기, `2` 퀴즈 등록, `3` 퀴즈 목록, `4` 점수 확인, `5` 종료를 선택한다. 각 기능이 끝나면 메뉴로 돌아온다.
4. 숫자 입력은 앞뒤 공백을 제거하고 검사한다. 빈 입력, 숫자 변환 실패, 허용 범위 밖의 값은 안내 후 같은 항목을 다시 입력받는다.

## 1. 퀴즈 풀기

1. 퀴즈 목록이 비어 있으면 안내하고 메뉴로 돌아간다.
2. 저장된 퀴즈를 목록 순서대로 모두 출제한다. 한 문항씩 문제와 선택지 4개를 보여주고 정답 번호 `1`~`4`를 입력받는다.
3. 각 답을 즉시 채점해 정오답을 안내한다. 정답은 5점, 오답은 0점이다.
4. 한 판을 마치면 전체 문항 수, 정답 수, 총점을 출력한다. 첫 완료 기록이거나 총점이 기존 최고 점수보다 높으면 최고 점수를 갱신하고 즉시 저장한다. 동점이면 기존 기록을 유지한다.

## 2. 퀴즈 등록

1. 문제와 선택지 4개를 입력받는다. 앞뒤 공백을 제거한 뒤 내용이 비어 있으면 해당 항목을 다시 입력받는다.
2. 정답 번호 `1`~`4`를 입력받고 문제, 선택지, 정답을 보여준 뒤 `예` 또는 `아니요`로 확인을 받는다. 기존 입력인 `yes`와 `no`도 지원한다. 그 외 입력은 다시 확인한다.
3. 등록을 확인하면 목록에 추가하고 즉시 저장한다. 취소하면 메뉴로 돌아간다.

## 3. 퀴즈 목록

메모리에 있는 퀴즈를 목록 순서대로 번호와 함께 보여준다. 목록이 비어 있으면 안내하고 메뉴로 돌아간다.

## 4. 점수 확인

현재 최고 점수를 보여준다. 아직 끝까지 푼 게임이 없다면 기록이 없다고 안내한다. 한 판을 완료해서 얻은 0점도 점수로 표시한다.

## 5. 저장 실패와 종료

- 저장에 실패하면 오류를 안내하고 완료된 변경은 메모리에 유지한다. 다음 저장 요청이나 종료 시 저장을 다시 시도한다.
- 메뉴의 종료, `Ctrl+C`, 입력 스트림 종료(`EOFError`)는 같은 종료 흐름으로 처리한다. 중단 시에는 안내를 표시하고, 완료된 변경 중 저장할 내용이 있으면 저장을 시도한 뒤 종료한다. 마지막 저장도 실패하면 사용자에게 알린다.
- 확인을 마치지 않은 등록과 도중에 중단된 게임은 기록에 반영하지 않는다.

## 보너스 기능

- **랜덤 출제와 문항 수 선택.** 목록이 비어 있는지 먼저 확인한다. `1`부터 `len(quizzes)`까지 입력을 받고 `random.sample(quizzes, k)`로 중복 없이 `k`개를 뽑는다. 최고 점수를 한 판 총점으로 비교하므로 문항 수가 많은 판의 최대 점수가 높다.
- **힌트.** 정답 번호 대신 `힌트`를 입력하면 힌트를 보여준다. 힌트를 본 문항은 정답 3점, 오답 0점으로 채점한다.
- **삭제.** 목록에서 문항을 선택하고 삭제를 확인하면 변경을 저장한다.
- **점수 히스토리.** 완료한 게임의 날짜와 시간, 문항 수, 총점 등을 저장한다. 점수 확인 메뉴에서 최근 기록을 조회할 수 있게 한다.

# 프로그램 개발 순서

1. `main.py`와 `QuizGame`으로 메뉴 반복, 공통 숫자 입력 처리, 정상 종료와 입력 중단 흐름을 만든다.
2. `Quiz`의 문항 표현 및 정답 확인을 구현하고, 직접 작성한 CS 퀴즈 5문항 이상을 기본 데이터로 구성한다.
3. [저장 형식](architecture.md#statejson)에 맞춰 UTF-8 JSON 읽기·쓰기를 구현한다. 파일 없음, 손상, 읽기·쓰기 실패를 점검한다.
4. 별도 브랜치에서 퀴즈 풀기와 즉시 채점을 구현한다. 한 판 결과와 최고 점수 갱신·저장을 확인한 뒤 커밋하고 `main`으로 병합한다.
5. 퀴즈 등록, 목록, 점수 확인을 구현하고 기능별로 검증한 뒤 커밋한다.
6. 퀴즈 등록과 최고 점수 갱신 후 재실행해 두 값이 유지되는지 확인한다. 빈 목록, 0점, 잘못된 입력, `Ctrl+C`와 EOF도 점검한다. README에 실행 방법, 기능, 파일 구조, 저장 파일을 정리한다.
7. 랜덤 출제, 문항 수 선택, 힌트, 삭제, 점수 히스토리를 추가한다.

기능별로 동작을 확인한 뒤 커밋하고, 제출 전에 의미 있는 커밋이 10개 이상인지 확인한다.
개발 중 `git clone`과 `git pull`을 각각 한 번 이상 사용하고, 제출 전에 사용 기록을 확인한다.
